# Netflix Landing Page Clone 

My first web development project — a Netflix-inspired landing page built using HTML and CSS.

I created this project while learning web development to practise building website layouts, styling elements, and making pages responsive across different screen sizes.

# Features

- Netflix-inspired landing page design
- Hero section with an email input and call-to-action button
- Trending Now section featuring 10 show cards
- Responsive layout for desktop, tablets, and mobile devices
- Horizontal scrolling sliders on smaller screens
- Reasons to Join section
- Frequently Asked Questions section
- Footer with navigation links

# Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

#What I Learned

While building this project, I practised:

- Structuring a webpage using HTML
- Styling layouts, buttons, and cards with CSS
- Using Flexbox and CSS Grid
- Working with images and file paths
- Creating responsive layouts using media queries
- Organizing project files and folders

# How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
